# NEXORA — Intelligent Payment Fraud Prevention

NEXORA is an AI-powered payment fraud detection prototype built for **CyberCup 6.0**. It combines machine learning, rule-based detection, and explainable risk scoring to identify suspicious digital payments before users proceed.

### ✨ Highlights

- 🤖 **AI-Based Fraud Detection** — Identifies potentially suspicious transactions.
- 🔍 **Context-Aware Analysis** — Detects intent-action mismatches, such as fake refund requests.
- 🇮🇳 **India-Specific Scenarios** — Targets scams involving UPI, QR codes, and remote access.
- ⚠️ **Explainable Warnings** — Shows users why a transaction may be risky.
- 📊 **Analyst Dashboard** — Displays flagged transactions and evaluation metrics.
- 🛡️ **Synthetic Data Testing** — Supports safe prototyping without real customer data or live payments.

*Our mission: Make digital payments smarter, safer, and more transparent.*
